# CodeOrbit Vela

## Project Title
Vela – Travel & Stay Discovery Landing Page

## Project Overview
Vela is a travel and stay discovery platform concept designed to help users discover thoughtfully selected stays and destinations for memorable escapes. The project focuses on creating a premium, clear, and engaging landing page experience.

## Key Sections
- Hero Section
- Why Vela
- Featured Stays
- Popular Destinations
- How Vela Works
- Traveller Testimonials
- Final Call-to-Action
- Footer

## Technologies Used
- Figma
- UI/UX Design
- High-Fidelity UI Design
- Responsive Layout Design

## Design Focus
- Premium and inviting visual style
- Clear visual hierarchy
- Consistent typography and spacing
- Warm and sophisticated colour palette
- Simple travel discovery experience
- Clear calls-to-action

## Setup Instructions
This project is a Figma-based UI/UX design project.

1. Open the shared Figma design link.
2. Review the landing page sections and visual design.
3. Explore the prototype interactions where available.
